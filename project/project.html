Foreign Direct Investment in Saudi Arabia

PP434 Project | Abdulaziz Alhakbani

1. Aims

This project analyzes trends in Foreign Direct Investment (FDI) in Saudi Arabia since 1990 to 2023. The main objective of the Vision 2030 strategy of Saudi Arabia is to diversify economy away from oil, and one of the main instruments the country is focusing on is attracting FDI to the Kingdom.

I will addresses three main questions: How have FDI evolved over time? How does the Kingdom compare to other similar GCC countries in attracting foreign investment? Which regions within the country dominate FDI activity?

3. Conclusions

The analysis reveals four key findings:

  1. Volatility: Saudi FDI shows high fluctuations but a noticable rise in the years after Vision 2030 strategy.
  2. Regional peers: Compared to UAE and Qatar, Saudi Arabia attracts lower FDI relative to GDP, singaling more room for growth in attracting investments.
  3. Investor concentration: The UAE and Luxembourg together account for over SAR 200 billion in FDI stock.
  4. Geographic concentration: The Eastern Region and Riyadh dominate FDI, reflecting oil industry and capital city effects.

Future work could examine FDI by sector to assess which non-oil industries are gaining traction under Vision 2030.

5. Tools & Methodology

Data Collection: Python scripts in Google Colab to download data from the World Bank API. For the Ministry of Investment data, I used multi-sheet Excel files, extracting specific rows/columns containing FDI by country (Sheet 4-1) and by region (Sheet 3-1). The regional map uses GeoJSON boundaries from OpenStreetMap, merged with FDI data via a lookup script.

Data Processing: API responses are parsed and filtered for null values, then exported to JSON. Excel extraction required mapping Arabic column headers to English region names and handling SAR millions to billions conversion.

Visualisation: All charts use Vega-Lite specifications. Charts 1-6 use live API data; Charts 7-8 use locally extracted JSON from the the Ministry of Investment bulletin. Consistent styling was applied across all charts.

Challenges: The Ministry Excel file has complex multi-header structures requiring manual row/column indexing. For the choropleth map, region names in the GeoJSON required matching to FDI data (e.g., "Ash Sharqiyah" → "Eastern Region").

Gen AI: I used Gen AI tools to troubleshoot and suggest ways to further improve the code and find sources for data.
